    Web application to <b>parse</b> lengthy travel blogs, extract tourist destinations and generate an itinerary. A <b>BERT-BiLSTM-CRF</b> model (768-dim BERT embeddings, bidirectional LSTM, linear-chain CRF decoder) achieves an <b>80.01% F1-score</b>; the output is fed to the <b>Mapbox Directions API</b> to plot an <b>efficient route</b> on a React frontend.
    <br><br>
    📄 Published as first author at <i>2023 IEEE 5th ICAECC</i> (IEEE Xplore-indexed). 🏆 <i>Sponsor track winner, Hack This Fall (506 participants, India-wide)</i>
    <br><br>
