excerpt: 'This research paper delves into the application of YOLO deep convolutional neural network (CNN) architectures for object detection in military surveillance. The performance of YOLOv3, YOLOv4, and YOLOv5m is compared on a publicly available military object detection dataset. A new dataset is created by expanding the classes in the public dataset. Finally, Slicing Aided Hyper Inference (SAHI) technique is applied to improve the performance of YOLOv5m in detecting small object instances located far away within a scene.'
